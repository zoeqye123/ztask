```markdown
- [ ] Task-知识整理-熵增主题笔记系统化 🔺 📅 2026-08-18 🏷️ #task 📁 ~/Obsidian Vault/03 Knowledge/

# Task: 知识整理｜熵增主题笔记系统化

## 背景
我对熵增有一定了解，但笔记散落在各处（物理/心理学/效率执行/哲学），没有形成体系。需要整理成一个相互关联的知识网络。

## 执行上下文
| 字段 | 值 |
|------|-----|
| **📁 执行文件夹** | `~/Obsidian Vault/03 Knowledge/` |
| **🛠 关联 Skills** | 无 |

## 目标
- [ ] 找出 Vault 中所有与熵相关的笔记
- [ ] 建立跨分类的熵增主题知识网络（≥ 8 条双向链接）
- [ ] 输出一张熵增主题地图（熵增地图.md）
- [ ] 识别 2 个可以深挖的熵增子主题

## 约束
- 不创建空壳笔记，每条笔记必须有实质内容（≥ 100 字）
- 双向链接必须有上下文（不是随意链接）
- 原子化：单条笔记只讲一个子概念

## 执行步骤

### Phase 1 · 收集熵相关笔记
1. 全文搜索 "熵" 或 "entropy"，列出所有相关笔记路径
2. 逐个读取，摘录核心论点

### Phase 2 · 建立知识网络
对每条相关笔记：
1. 在笔记末尾补充"熵增主题关联"区块
2. 链接到其他熵相关笔记（必须有逻辑关联）
3. 记录链接关系（用于画地图）

### Phase 3 · 输出主题地图
创建 `熵增地图.md`：
- 一张网络图（用文字表示）：主题 → 分支 → 关联
- 说明每个节点是什么、链接关系
- 标注 2 个值得深挖的子主题

## 验收标准
- [ ] 找到 ≥ 8 条熵相关笔记
- [ ] 熵增主题网络包含 ≥ 8 条双向链接
- [ ] `熵增地图.md` 存在且结构清晰
- [ ] 识别出 2 个可深挖子主题，并说明为什么值得深挖
```
