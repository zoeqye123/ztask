# Task: 竞品分析｜差异化策略

> 示例 Task，展示如何用 TaskBrain 驱动 AI 完成一份调研报告

```markdown
- [ ] Task-竞品分析-差异化策略 🔺 📅 2026-08-15 🏷️ #task 📁 ~/projects/strategy/

# Task: 竞品分析｜差异化策略

## 背景
我们需要搞清楚竞品的差异化路线，为下季度产品方向提供依据。

## 执行上下文
| 字段 | 值 |
|------|-----|
| **📁 执行文件夹** | `~/projects/strategy/` |
| **🛠 关联 Skills** | `research`（如无，可忽略此字段） |

## 目标
- [ ] 完成 5 家主要竞品的差异化分析
- [ ] 每家覆盖：定价策略 / 核心功能 / 目标用户 / 市场定位
- [ ] 输出 1 页策略摘要（.md + .docx）

## 执行步骤

### Phase 1 · 建立分析框架
1. 创建 `竞品分析框架.md`，定义分析维度（定价/功能/定位/用户）
2. 整理竞品清单，确认 5 家分析对象

### Phase 2 · 逐个分析
对每家竞品：
1. 收集公开信息（官网/产品页/公开数据）
2. 填写分析框架
3. 提炼 1 条差异化亮点

### Phase 3 · 策略摘要
1. 对比 5 家，找出共同趋势
2. 提炼 3 条差异化洞察
3. 写成 `竞品分析报告.md` 和 `竞品分析报告.docx`

## 验收标准
- [ ] 5 家竞品全部覆盖
- [ ] 每家有 4 个维度的分析内容
- [ ] 有 3 条差异化洞察
- [ ] 输出 .md + .docx 两份文件
```
